# mysport
秒燃 —— 专注于间歇训练的计时助手，让每一次训练节奏清晰、动作到位。

无论是 Tabata、HIIT、EMOM 还是自编排的循环训练，只需几步即可创建专属计划：选择动作、设定时长与轮次，剩下的交给秒燃。训练全程提供准备倒计时、阶段变色提示、中文语音播报与音效震动反馈，你只需专注于动作本身。

【核心功能】

▸ 灵活的训练计划
· 自由创建：动作、时长、组间休息、循环轮次全部自定义
· 经典模板：内置 Tabata 经典、Little Method、EMOM、新手 HIIT、核心力量等预设
· 计时/计数双模式：计时动作自动倒计时，计数动作显示目标次数
· 支持置顶、归档、复制与分类管理，训练库井井有条

▸ 专业的训练计时体验
· 准备 10 秒倒计时，从容进入状态
· 训练/休息阶段界面自动变色，一眼识别当前状态
· 最后 3 秒音效与震动提示，语音预告下一个动作
· 训练期间屏幕常亮，随时暂停、跳过或回退

▸ 数据统计与激励体系
· 总消耗、总时长、训练次数一目了然
· 周/月训练趋势图表
· 9 枚成就勋章，从初次启航到百炼成钢
· 连续训练天数记录，帮助养成运动习惯

▸ Apple Watch 同步
· 计划与记录自动同步至手表，手表也能独立开始训练

▸ 隐私优先
· 无需注册登录，不收集个人身份信息
· 训练数据仅存储在本机

温馨提示：训练前请充分热身，量力而行；如有不适请立即停止，必要时咨询专业医生。

坚持，从一次 4 分钟的 Tabata 开始。今天就打开秒燃，完成你的第一组训练吧！
